# BallotBuilder

[![Test](https://github.com/nightlymath/BallotBuilder/actions/workflows/test.yml/badge.svg)](https://github.com/nightlymath/BallotBuilder/actions/workflows/test.yml)

Tool for voters to generate a sample election ballot

## Dev in container (recommended)

This repository includes a reproducible developer container and CI validation for container images. See `specs/002-dockerize-app/quickstart.md` for full instructions.

Quick start:

- Build and run dev container (Linux/macOS):

  ```bash
  ./scripts/dev-in-container.sh
  ```

- Reproduce CI validation locally:

  ```bash
  ./scripts/validate-container.sh
  ```
